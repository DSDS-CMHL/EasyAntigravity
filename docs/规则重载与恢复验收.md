2026-10-12，用户关闭 EasyAG 后，AG 配置从 EAGER 恢复到原来的 OFF；本轮注入的 19 条 Ask 全部撤回，原有手动 Ask 保留，其他配置无变化，permission-session.json 已清除。本轮只验证配置文件恢复，不证明正在运行的 AG 已即时重载。

## v3.2.1 修复边界

- 活跃 Pilot 会话重载后，按当前会话防护档位重新编译并更新 AG 的 Allow / Deny / Ask。
- 只替换本会话拥有的规则，保留用户原有规则、运行期间新增的规则和修改后的自动执行策略。
- 支持禁用全部规则后重载；恢复记录仍保留，以便退出时恢复原策略。
- 配置写入前持久化旧、新注入规则并集；成功后收敛到新规则。失败或中途退出仍保留可恢复记录，不在重载失败时自动关闭 Turbo。
- 兼容模式、仅打开启动器而未启动 Pilot 时，重载只更新本地规则引擎，不修改 AG 权限。启动或退出期间拒绝重载。
- 写入成功与 AG 即时生效分开：界面不宣称实机已验证。
- issue #7 的空对象、缺失数组和 null 归一化由独立 permission-config 模块处理，恢复时保留原结构。非法非空结构报错，不静默丢弃用户数据。
