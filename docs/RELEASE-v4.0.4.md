EasyAG v4.0.4 Lite 汇总启动、路径配置、代理切换、上下文监控和 macOS 外壳修复。

## 本次更新

- 支持桌面版与 IDE 版启动目标切换，自动检测安装位置。
- 找不到程序时自动弹出路径设置窗口，支持浏览、手动输入和恢复默认；自定义路径会保存。默认安装正常时不显示路径设置。
- 修复路径弹窗改版后，启动按钮、版本切换、主题和检查更新等操作失效的问题。
- 路径弹窗支持取消、关闭、Escape 和点击背景关闭；定时刷新不会覆盖正在输入的路径。取消后再次点击启动可重新打开。
- 免 TUN 代理支持开关，直连环境可以关闭；启动中及运行时锁定代理设置和启动目标。
- 提高较长会话的上下文采集响应上限，并改善模型名称解析、窗口布局与版本按钮显示。
- macOS 隐藏窗口后隐藏 Dock 图标，通过顶部菜单栏重新打开窗口。
- 屏蔽启动器中打印、另存为、刷新等默认浏览器右键菜单。
- 热更新跳过未变化的文件，延长更新请求超时；更新清单包含此次正式修复。

## 如何升级

### Windows：点击“检查更新”即可

已有 Windows Lite 版用户无需重新下载便携包。在 EasyAG 顶栏点击 **“检查更新”**，等待更新完成后，**从托盘彻底退出 EasyAG，再重新打开**，即可使用本次后台与界面修复。

### macOS：重新下载以更新 Dock 行为

Dock 图标的显示与隐藏属于原生外壳功能，内置热更新无法替换。请按 Mac 芯片类型下载下方完整包，退出 EasyAG 后替换整个应用。原有用户配置可保留。

### 首次使用与完整包下载

| 系统 | 下载文件 |
| --- | --- |
| Windows x64 | `EasyAntigravity-4.0.4-lite-windows-x64.zip` |
| macOS Apple Silicon | `EasyAntigravity-4.0.4-lite-macos-arm64-beta.zip` |
| macOS Intel | `EasyAntigravity-4.0.4-lite-macos-x64-beta.zip` |

Windows 新用户请完整解压，运行 `EasyAntigravity.exe`，保留同目录的运行环境和 backend 文件夹。macOS 仍为 Beta，未经过 Apple 公证。

> 特殊情况：如果界面已显示内部测试版 **4.0.4**，或“检查更新”按钮无法使用，请下载本次完整包。旧更新器会跳过同版本补丁，无法通过再次检查更新取得此次修复。

CLI Companion 在 `cli-edition` 分支独立开发和发布，不包含在本次发行中。

## 验证范围

发布流程运行后端测试、Windows 浏览器交互回归、便携资源及后台生命周期检查，并重新构建三个平台的原生应用。

Windows 自定义路径拉起程序已实测；macOS Dock 行为仍需 Mac 实机确认。IDE 与桌面版的增强能力不同，能启动程序不代表所有增强功能均受支持。
