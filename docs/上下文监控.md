# AG 内上下文监控

## 首版范围

常驻条只显示图形与数字，不放文字标签：

- 上下文：圆环填充反映占用，中心显示百分数值（如 `43`）；满容量圆环填满。点击展开占用/容量、采样模型、最近有效请求生成速度、该请求首 token 等待和采集时间。
- 风险：盾牌内显示最近一次风险命中等级的本次会话累计次数，不显示总数、不定时轮播。高风险红色、中风险黄色、低风险蓝色；无记录时显示中性 0，未同步时显示 —。一位数 11px、两位数 9px、三位数 7px，超过 999 显示 6px 的 999+；悬停保留准确分类次数，并注明风险命中不代表已阻止执行。点击展开高/中/低及总数，风险详情卡宽 208px，上下文详情保持 304px。

文字仅用于悬停说明、无障碍名称和展开详情。两个详情互斥，均可关闭、再次打开、Escape 或外部点击关闭。

不做额度显示、主动限速、账号切换、对话列表、缓存命中率、工具耗时或历史统计。上下文独立于 Pilot/兼容模式，默认开启，可在启动器里实时关闭。风险入口随 Pilot/ARES 显示；关闭上下文仍保留风险入口，兼容模式不显示风险入口。

风险计数直接取 `RiskAdvisor` 的 ARES 观察事件，与启动器日志中的风险次数同源，不解析日志文字。不统计原生审批次数、允许/拒绝结果，也不称为“已阻止命令”。分类计数与总数同时更新；同一次观察沿用既有 invocation 去重。成功开始新的 AG 会话时重置，切换对话、注入重载或关闭详情均不重置。不落盘，重启 EasyAG 后不恢复历史统计。

上下文为 AG 最近一次请求开始时提供的估算，不是逐 token 实时计数，也不表示模型记忆质量。缺少容量显示“容量未知”，没有数据显示 `—`；压缩后占用可以下降。百分比超过 100% 时保留真实比值，不强制伪装成 100%。

速度是最近有效请求的输出 token / 流式时长，不包含 TTFT；字段不足时标明“按总输出计算”，短样本提示波动。无有效时长不编造速度。详情标明采样模型，可能不同于刚切换后尚未产生样本的新模型。

## 模块边界

| 模块 | 责任 |
| --- | --- |
| `adapters/desktop/language-service-discovery.js` | 当前用户的语言服务进程与其 PID 所属 HTTP 端口发现 |
| `adapters/desktop/language-service.js` | 固定白名单只读 RPC、凭据保管、响应上限、请求取消与元数据分页 |
| `features/context-monitor.js` | 数值校验、上下文与速度统计、并发合并、账号/后台代次验证 |
| `features/risk-advisor.js` | ARES 事件去重、总数与高/中/低统计快照；现有提示与规则逻辑不变 |
| `features/context-widget.js` | Shadow DOM 双图形入口与详情、路由切换、避让、独立轮询与清理 |
| `adapters/desktop/cdp.js` | 复用调试连接，校验主 frame、页面来源、对话 ID 与注入代次，传送统计 |
| `desktop/application.js` | 设置与现有会话生命周期接线 |

不增加 Python、第三方插件或新依赖。参考项目的解析器与几何检查改编保留在 `THIRD-PARTY-NOTICES.md`，打包时一并携带；独立参考副本 `.reference/` 不进入 Git。

## 侵入性与隐私边界

- 不修改 AG 安装文件、插件注册、审批设置或工作区文件访问设置。
- 内嵌展示仍属于 CDP 运行时注入，会向页面增加一个自有节点；不能称为零侵入或官方扩展插槽。
- 本地 RPC 凭据仅留在后台内存，不交给页面、不落盘、不输出原始错误。
- 接口暂时需要获取当前对话轨迹，原始响应可能包含正文。提取元数据后释放轨迹引用，不查询其他对话、不保存原始响应或历史。
- 渲染页面仅接收对话 ID、状态、时间戳、采样模型名与白名单数值，不接收邮箱、账号哈希、正文、轨迹、凭据。
- 采集前后检查账号与后台一致；重连/关闭/关闭开关时废弃旧请求。切换对话立即清空旧显示。
- 页面隐藏或标记因空间不足而隐藏时不发起新采集；上下文约每 3 秒一次，风险快照约每秒一次。两者请求互不占用并发预算，上下文 RPC 慢或失败不会阻塞风险数字。
- 多个语言服务后台时暂不采集，不猜测属于哪个 AG。当前版本尚未实现由启动 PID 精确绑定多个后台。

## 展示与降级

首版只认明确的主会话模型选择器和邻近的语义编辑区，不使用泛化 combobox 回退。子代理、未知布局、非 `/c/<GUID>` 路由暂不挂载，避免误占原生控件。

窄窗口、原生控件重叠、原生按钮内容受挤压时隐藏标记，拉宽再恢复。输入区外浮动控件实际覆盖标记时同样隐藏，控件移开后恢复。不修改原生控件样式。

详情优先使用浏览器 popover 顶层；不支持时回退固定定位。支持关闭按钮、Escape、外部点击和再次打开。停用与退出清理自身节点、定时器、观察器和监听器。
