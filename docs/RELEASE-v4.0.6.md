# EasyAG v4.0.6 Lite

- 修复长对话下上下文统计、圆环布局检测和汉化监听的重复开销（#20）。
- 元数据增量缓存支持流式尾条刷新、会话截断恢复及定期重新同步。
- macOS 菜单栏改用随系统深浅背景适配的单色 Template 图标（#21）。

Windows：使用应用内热更新，完成后完全退出并重启 EasyAntigravity 即可，无需更换 EXE。

macOS：下载对应架构的 ZIP 并替换应用；arm64 适用于 Apple Silicon，x64 适用于 Intel。
安装包延续现有 Beta 分发方式，使用 ad-hoc 签名，未进行 Apple 公证。
