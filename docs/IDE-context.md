# IDE 上下文圆环接入

随 4.0.4 修订包分发，并纳入热更新清单。已安装旧 4.0.4 的用户需下载修订包，旧更新器不会重复安装同版本补丁。

IDE 与桌面版复用上下文摘要和圆环显示；IDE 仅接入上下文与速度，不向工作台注入桌面版翻译。

## 会话与后台

IDE 工作台的地址不会随聊天会话变化。接入通过当前可见聊天输入框的 Preact 组件读取 `cascadeId`，不读取会话正文，也不以历史列表或最近更新时间猜测当前会话。空白新会话、多个可见输入框、未知布局和无法确认的组件树返回不可用；切换会话时立即清空旧数据。

统计桥在请求前和返回前独立确认当前会话 ID，避免同一页面切换会话后显示旧结果。

IDE 对话后台使用独立的语言服务进程，排除代码补全用的 `--enable_lsp` 进程，只接受当前用户的 IDE 对话后台。由 EasyAG 启动时进一步绑定启动进程的直接子进程；连接已有实例时要求唯一候选。

仅在已验证的后台 PID 所属监听端口上探测白名单只读状态接口，随后读取当前会话元数据。认证信息仅在后台内存使用，不传给页面。账号、后台与采集代次变化后放弃旧结果。

## 显示与安全限制

IDE 使用 Trusted Types，禁止未经授权的 `innerHTML`。圆环与详情改用标准 DOM/SVG 方法创建，不新增 Trusted Types 策略，也不修改工作台安全设置。

圆环放在模型选择器附近，复用窄布局与原生按钮避让。支持详情、关闭、外部点击和 Escape；关闭上下文开关或退出采集会移除自身节点及监听器。

## 验证

- Windows 实机：由用户通过 EasyAG 启动、带代理且已登录的 IDE 中，成功读取当前会话上下文、模型与速度，并显示圆环。
- 单元测试：当前输入框绑定、空白与歧义拒绝、同页面切换、后台筛选、只读端口探测、返回前会话复核及桌面/IDE 页面隔离。
- Chromium 模拟页面：桌面路由与 IDE 同页面会话切换；IDE 页面强制 Trusted Types，验证圆环、详情、关闭、避让及清理。
- 用户已确认重启 EasyAG 后圆环自动接入，显示与基本使用正常。长会话压缩及持续使用仍需更多验证；macOS 未实机验证。

```sh
npm run test:context
npm run test:context:browser -- "浏览器可执行文件完整路径"
npm run test:context:browser:ide -- "浏览器可执行文件完整路径"
```
