## 二、实操演示与录屏准备 Checklist

在录制前，先准备好以下实机画面素材：

- [ ] **场景 A：代理报错与正常免 TUN 对比**
  - 关闭系统 TUN 模式，展示直连时登录失败或代理报错；
  - 启动 EasyAG，配置端口（如 7890），点击「启动 Antigravity」，秒速加载登录成功。
- [ ] **场景 B：汉化与双向无损还原**
  - 展示 Antigravity 界面全中文化；
  - 特写显示：Agent 思考流（Thought 过程）、终端输入、代码块保持纯英文；
  - 在 EasyAG 控制面板切关汉化开关，Antigravity 界面无刷新瞬间变回英文，再次打开瞬间恢复中文。
- [ ] **场景 C：高危拦截与 Turbo 翻车对比（重头戏）**
  - **准备空目录**：`F:\test-turbo-wipe`
  - **官方 Turbo 翻车录屏**：演示在官方设置中将 `rmdir` 设为 Ask，但在终端/Prompt 中执行带路径的 `cmd /c rmdir /s /q "F:\test-turbo-wipe"`，官方全字匹配漏网，毫秒级直接静默全放行，目录直接蒸发！
  - **EasyAG 熔断实测**：同一命令在 EasyAG 监控下执行，EasyAG 瞬间捕获，面板输出红字 `[SECURITY ALERT]`，按钮锁定为 Blocked，绝对不自动点击，控制台红色警报闪烁！
- [ ] **场景 D：普通命令正常放行**
  - 让 AI 运行 `git status` 或 `npm run build`，200ms 内自动勾选「仅允许本次」并放行，计数器 +1。
- [ ] **场景 E：方案选择题（薄荷青高亮）**
  - 让 Agent 提出包含多个方案的选项卡片（非权限卡片），卡片打上薄荷荧光青（`#00f5d4`）高亮标签，EasyAG 暂停操作，日志提示方案问答静候人工决策。
- [ ] **场景 F：8 阶段自动化测试套件高燃画面**
  - 运行命令录屏：
    ```powershell
    node test/standard-workflow.test.js
    ```
    录制控制台 8 大测试阶段全 PASS 的整齐表格输出，作为极具极客说服力的技术底色。
