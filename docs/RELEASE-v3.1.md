# EasyAG v3.1（3.1.0）

## 本版改动

- 权限正则编译保留 ASCII 大小写匹配能力，保留已实测的 AG 正则外层格式。
- 调整删除参数后置、wevtutil cl、Git clean 预览、普通数据管道、计划任务查询、crontab 查看和 diskpart 帮助相关规则。
- 仅升级未修改的旧版默认表达式，保留用户自定义规则、开关和审批动作。
- 风险通知按命令步骤去重；原生弹窗消息单次送达，避免旧消息延迟覆盖新消息。
- 风险后果优先使用 ARES 文案，不再直接回退到内部工具列表。
- issue #7：独立权限配置结构模块支持空对象、缺失列表和 null，退出恢复原结构，保留用户后来新增的规则。

## 验证范围与已知限制

本地 B/P 字符串匹配与内存回归通过，但不是 AG 原生审批和弹窗的实机验收。

扩展轮仍记录了 8 条漏报、8 条误报及通知差异，尚未在本版修复；不能视为完整的 shell 安全边界或全危险命令覆盖。

详细探针和本地预测见 [扩展测试记录](AG-攻防测试记录-扩展.md)。扩展审计独立于发布回归，发现缺口时明确返回失败，不将缺口隐藏为通过。

验收时请使用本版完整目录，完全退出旧版 EasyAG 与 AG，再由新版 Turbo Pilot 启动。先确认实际规则写入，再做少量 echo 冒烟检查；不需要逐条跑完整扩展表。
