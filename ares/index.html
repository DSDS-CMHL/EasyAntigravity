场景：勒索软件前置动作，抹掉系统还原点后再加密。处方：保留卷影，仅删除指定旧快照并要求书面备份确认。

wbadmin delete catalog
HIGH 删备份编目 T1490

场景：销毁 Windows Server Backup 编目，使恢复不可用。处方：只做校验/列表，恢复需人工在控制台完成。

takeown /f <path> /r /d y && icacls <path> /grant Everyone:F /t
HIGH 全局夺权 / ACL 打乱 T1222

场景：接管系统目录权限并放通 Everyone，掩盖后续篡改。处方：最小权限，仅对项目工作区改 ACL，禁止 /t 递归到盘根。

diskpart /s <script> // clean / format / delete partition
CRITICAL 静默清盘 T1485

场景：脚本化 wipe 整盘或分区。处方：Agent 一律拒绝；磁盘操作只在恢复环境人工执行。

reg delete <key> /f
HIGH 注册表强制抹除 T1112

场景：删除 Run/服务/防火墙键，破坏持久化与防护。处方：导出 .reg 备份后再改，禁止批量 /f 删除 HKLM。

git push -f | --force | -force
HIGH 强制覆盖主干分支 处方：--force-with-lease

处方：改用 git push --force-with-lease；push 前 git fetch 并确认远程无新提交。

git reset --hard HEAD~N
HIGH 丢弃未提交及历史 处方：stash / 检出新分支

处方：先 git stash push -m "ares-backup" 或建 backup/… 分支，再 reset。

git clean -fdx
HIGH 递归抹除非追踪与构建文件 处方：clean -nd 预览

处方：先 git clean -nd 列出将删文件，人工确认后再 -fd；慎用 -x 连缓存一起清。

git branch -D <branch>
MEDIUM 强制删除未合并分支 处方：-d / 记录 SHA

处方：优先 git branch -d；确需 -D 时先打印分支头 SHA 以便恢复。
